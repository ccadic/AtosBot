# AtosBot

Indicateurs analysés :

Bandes de Bollinger : Identifie les zones de survente et de surachat.
RSI (Relative Strength Index - 14 périodes) : Évalue la force du marché et détecte les retournements de tendance.
Conditions d'alerte :
Un signal d’achat est généré lorsque :

Le cours touche la bande de Bollinger inférieure (signe de survente).
Le RSI est inférieur à 55 (potentiel retournement haussier).
